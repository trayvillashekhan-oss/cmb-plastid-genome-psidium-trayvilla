# Galaxy Analysis Results

This folder contains the sequence analysis results for the complete chloroplast genome of Psidium guajava (NC_033355.1).
- Genome length: 158,841 bp
- Number of sequence records: 1
- Galaxy tool: Compute sequence length
- Galaxy history: Plastid_Psidium_Trayvilla
- GC content: approximately 37%
- GC content analysis tool: geecee

## Plastid Genome Organization

The complete chloroplast genome of Psidium guajava (NC_033355.1) is 158,841 bp long and has a circular, quadripartite structure.

- Large single-copy (LSC): 87,675 bp
- Small single-copy (SSC): 18,464 bp
- Inverted repeat A (IRa): 26,351 bp
- Inverted repeat B (IRb): 26,351 bp

These region sizes were obtained from Jo et al. (2016), rather than calculated directly in Galaxy.

Reference:
Jo, S., et al. (2016). Complete plastome sequence of Psidium guajava L. (Myrtaceae). Mitochondrial DNA Part B, 1(1), 612–614.
